# A1 透天｜全棟 3D 家具搭配

依原建商「傢俱配置參考圖」與 2021 毛胚屋影片建立的全棟 3D 模型（1F 車庫・孝親房、2F 客餐廚、3F 臥室、4F 主臥・露台），可以：

- 分樓層剖切檢視，或切換「客廳 85 吋」「主臥」「車庫玄關」等模擬視角
- 點家具更換 IKEA／特力屋款式與顏色，即時看到搭配效果，並檢查放不放得下
- 一鍵套用「暖木灰／黑白極簡／自然綠意」配色
- 產生購物清單，連到官網搜尋實品

尺寸為比例示意，家具尺寸為參考值，下單前請實際丈量並以官網為準。

## 發佈成網頁（GitHub Pages）

1. 在 GitHub 建立新的 repository（例如 `a1-house-3d`），上傳這個資料夾的所有檔案。
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約一分鐘後，網址會是 `https://<你的帳號>.github.io/a1-house-3d/`。

免費方案的 GitHub Pages 需要公開 repository，網頁任何人都看得到；檔案中不含地址與照片。

## 修改家具清單

家具型錄在 `index.html` 的 `CAT` 物件裡，每一款包含品牌、名稱、寬深高（cm）、顏色與搜尋關鍵字；擺放位置在 `SLOTS`。新增款式只要照格式多加一筆即可。
